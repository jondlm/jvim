# Jon's Dotfiles

These are my dotfiles. I wouldn't recommend using them directly. They change
often and are subject to my whims. Instead, feel free to peek at individual
files for inspiration.

## Installation

Prerequisites:
- Atuin
- Carapace
- Fzf
- Ghostty
- Mise
- Neovim
- Nushell
- Ripgrep
- Starship
- Tmux
- Zoxide

1. `git clone git@github.com:jondlm/jvim ~/.jvim && cd ~/.jvim`
2. `./install`
